PORTFOLIO

A small sampling of some of the projects I've worked on as a student of the IMD Program.

WebMart - Low Fidelity Prototype

This project represents the low-fidelity prototype of an e-commerce website called WebMart. I designed it from scratch to establish the core layout, navigation flow, and user experience framework. This stage focused on translating ideas into structured wireframes, setting the groundwork for the later high-fidelity design and development phase.

WebMart High Fidelity Prototype

This is a high-fidelity prototype of Webmart, an e-commerce platform concept designed in Figma. I focused on creating a clean, modern, and user-friendly interface with well-structured layouts and consistent branding elements. The design is fully interactive and development-ready, highlighting my skills in UI/UX design, visual composition, typography, and attention to detail throughout the user flow.

FoodSwift Prototype

My first Figma project focused on mastering Figma tools by designing a food delivery app called FoodSwift. The project involved developing the app from low-fidelity wireframes to high-fidelity prototypes, refining user interface elements and interactions to create a seamless user experience.

Cattitude High-Fidelity Prototype

This is my final Design Thinking project, created as a mobile app prototype ready for deployment. The app helps cat owners and animal lovers learn more about various cat breeds, traits, and behaviors. A key feature of the app is an integrated image recognition system that lets users identify their cat’s breed instantly through the in-app camera, showcasing both functionality and user-centered design principles.

Canada Events Finder Website

Canada Events Finder is an interactive web application designed to display and manage upcoming events throughout Canada. Developed entirely with Vanilla JavaScript, it utilizes the Ticketmaster API to retrieve live event data and Leaflet.js for advanced map functionality, including custom markers, dynamic popups, and city-based filtering. Users can also save events and add new pins, showcasing both front-end development and API integration skills.

Procreate Painting

This Procreate painting is a personal project where I’m learning to use Procreate by painting the faces of two people, referencing an open-source image found online. Through this work, I’m exploring digital techniques, refining my brushwork, and developing my skills in capturing realistic expressions.
